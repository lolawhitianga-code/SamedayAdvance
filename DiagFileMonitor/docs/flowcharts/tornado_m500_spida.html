TORNADO M500 // AUTOMATED LINEAR SAW // OP GUIDE REV 1.0

Tornado M500

7-AXIS · AUTOMATED · INFEED → SAW CABINET → OUTFEED · DUAL PRINTERS · 500mm BLADE

CABINET CLEAR RULE — BEFORE ANY INFEED LOADING:
All 4 cabinet clamps must show OPEN (reed switch sensors ON): 2 horizontal + 2 vertical. Both cabinet eye sensors must be NOT detecting timber. Top printer must be UP (above timber stack height). If any cabinet eye sensor detects timber when Start Board is pressed → infeed does NOT load → infeed rollers run BACKWARDS to eject until sensors clear.

TROUBLESHOOTING: If nothing loads after pressing Start Board, check cabinet eye sensors — sawdust buildup may be triggering false detection. Clean sensors and retry.
TIMBER SIZE TOLERANCE RULE:
After first horizontal and vertical clamps engage, analog sensors measure actual stack height and width. Tolerance is ~10%. If outside tolerance → machine stops → operator decides to continue or reload. Example: triple stack 90×45mm = 90mm wide, 135mm tall ±10%.
POST LASER — BOARD LENGTH CHECK:
Before pushing begins, the post laser measures actual board length against stock length.
· Board LONGER than stock → process regardless, software adds extra waste.
· Board SHORTER than stock but has waste → recalculate, remove waste, process.
· Board TOO SHORT — members won't fit → machine stops → operator chooses: continue anyway or reload correct timber.
MEMBER LENGTH — WASTE CONVEYOR vs OUTFEED:
Members <~520mm → drop down to waste conveyor below saw cabinet → conveyor drives RIGHT if waste, or LEFT if usable offcut.
Members >~520mm → driven out via outfeed rollers to outfeed deck.
SHORT MEMBER SUPPORT:
If a member is classified as short, the short support flap rises just before the cut is made to prevent it falling inside the cabinet during cutting.

STEP // 01
Home All 7 Servo Axes
Operator commands HOME. All 7 axes drive to home reference positions: Pusher, Saw Blade Angle, Saw Blade Offset (forward/backward), Saw Up/Down, Top Printer Up/Down, Outfeed Rollers, Infeed Rollers. Controller confirms all axes referenced and ready.

CABINET CLEAR CHECK — AUTO BEFORE EVERY BOARD
CHECK // 01
Cabinet Eye Sensors Clear?
Program checks both cabinet eye sensors. If neither is detecting timber — cabinet is clear. Proceed to infeed sequence. If either sensor detects timber → infeed does NOT load → infeed drive rollers run BACKWARDS to eject timber until both sensors clear.

INFEED AUTO SEQUENCE
INFEED — FULLY AUTOMATED AFTER START BOARD
CHECK // 02
Deck DOWN Sensor Confirmed
Before chains can drive, the infeed deck (cylinder driven) must be confirmed DOWN. Deck DOWN sensor must be active before chains are permitted to move.
CHECK
CHECK // 03
Gripper Eye Sensors All Clear?
Before chains can drive, all 4 gripper eye sensors must be OFF — not detecting anything. If any one gripper eye sensor is detecting → chains will NOT drive → machine pauses → log displays error: "HAV INFEED" (timber detected on infeed). Operator must clear the obstruction before the machine can continue.
CHECK
STEP // 05
Infeed Chains Drive Timber Forward
Infeed chains (VFD driven) drive forward, advancing the timber stack toward the grippers and saw cabinet entry.
AUTO
CHECK // 04
3 Sensors Must Confirm Before Grippers Can Grip
Chains stop when all 3 conditions are met: (1) Entry sensor (closest to saw cabinet) detects timber is correctly loaded flush to the infeed loading point. (2) Any 2 of the 4 gripper eye sensors (upward-facing, one per gripper) detect timber flush up against the fence. Once all 3 confirmed → grippers grip the timber stack (1, 2, or 3 boards high).
CHECK
STEP // 06
Chains Reverse — Gap Created Between Boards
Infeed chains drive backwards slightly while grippers hold the timber. This creates a gap between the grabbed boards and the remaining timber on the infeed deck.
AUTO
STEP // 07
Deck Lifts UP — Supports Timber
Infeed deck cylinder extends, lifting the deck UP to support the timber from below. Deck UP sensor must be confirmed active before grippers are permitted to release.
AUTO
STEP // 08
Grippers Release Timber Against Fence — Move Out of Way
Deck UP sensor confirmed. Grippers pull timber to the fence line (a few mm) and release. Timber rests on the supported deck against the fence. Grippers move further inside fence line, out of the way. Gripper sensors confirm gripped/ungripped and in/out positions throughout.
AUTO
STEP // 09
The pusher (long arm at far end of infeed) servo-drives to the position matching the expected stock length of this board.
AUTO
CHECK // 05
Post Laser — Measures Actual Board Length
Post laser fires down onto the end of the timber and measures actual board length against the expected stock length. See Post Laser rule box at top for all 3 outcomes. If too short and members won't fit → machine stops → operator decides to continue or reload.
CHECK
STEP // 10
Pusher Laser Drops 70mm — Confirms Board Exists
Pusher drops its own laser 70mm behind the end of the board to confirm the board actually exists at that position. Board confirmed → pusher slowly moves forward until it touches the board, then begins pushing the timber into the saw cabinet.
AUTO
STEP // 11
Board Pushed Into Cabinet — Deck Sent DOWN
Board has been fully pushed into the saw cabinet. Infeed deck cylinder retracts, sending the deck DOWN. Deck DOWN sensor must confirm before chains are permitted to drive forward for the next board.
AUTO
SAW CABINET — ENTRY & MEASUREMENT
SAW CABINET ENTRY — ALL CHECKS MUST PASS
CHECK // 06
Cabinet Entry Checks — All Clear
Program confirms all 4 clamp sensors showing OPEN (2 horizontal + 2 vertical reed switch sensors ON). Both cabinet eye sensors not detecting timber. Top printer servo UP — above timber stack height and out of the way. All clear → pusher continues pushing timber in.
CHECK
CHECK // 07
First Clamps Engage — Analog Size Measurement
First horizontal clamp and first vertical clamp engage. Analog sensors on cylinders measure actual stack height and width. Compared against expected size ±10% tolerance. Within tolerance → pusher continues. Outside tolerance → machine stops → operator decides: continue or reload.
CHECK
STEP // 12
Saw Blade Starts Spinning (First Board Only)
If this is the first board of the batch, the saw blade starts spinning now. On subsequent boards it will already be spinning. Saw blade servo moves to the required angle and offset position, then rises above the timber stack height ready for the first cut.
AUTO
CUT SEQUENCE — REPEATS FOR EVERY CUT ON THE BOARD
CUT CYCLE — FULLY AUTOMATED · REPEATS PER CUT POSITION
STEP // 13
Pusher Advances — Timber to Cut Position
Pusher servo drives timber to the exact cut position for this cut. First cut is typically a trim cut (10–20mm off the front of the board, based on settings). Outfeed eye sensors detect timber as it advances — outfeed clamps engage progressively.
AUTO
STEP // 14
Outfeed Clamps Engage Progressively
As timber advances into the outfeed: 1st eye sensor detects → 1st horizontal + vertical clamp engage. 2nd eye sensor detects → 2nd horizontal + vertical clamp engage. Outfeed clamps are on rollers — pusher can continue pushing while clamps are engaged. Short support flap rises just before the cut is made if member is classified as short.
AUTO
STEP // 15
Both Printers Print Simultaneously
Fixed back printer and top printer (servo-positioned to correct height) both fire simultaneously, marking the timber just before the saw blade position. Top printer servo has already been positioned to the correct height for this timber stack.
AUTO

STEP // 16
Saw Blade Cuts — Timber at Cut Position
Saw blade (already spinning and at correct angle + offset) cuts through the timber stack. Off-cut drops. Saw blade rises back up after cut completes.

Outfeed Completes + Eye Sensors Clear + Pusher Returns
Three things complete simultaneously: (1) Both outfeed eye sensors turn off — timber fully cleared. (2) Outfeed rollers finish their drive run (~5 metres). (3) Pusher servo returns to waiting position ready for next board. Once all three are done, infeed chains start driving forward for the next board.
