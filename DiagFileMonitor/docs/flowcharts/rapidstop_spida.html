RAPID STOP // REFERENCE STOCK SAW // OP GUIDE REV 1.0

Rapid Stop
Operation Flowchart

SINGLE TROLLEY · FIXED 90° BLADE · AUTOMATED MEMBER CUTTING

▶ START — POWER ON
STARTUP
PRE-HOME CHECK
CHECK // PRE-HOME
Saw Back Sensor Must Be ON Before Homing
Before the trolley can be homed, the saw back sensor must be confirmed ON — saw is fully retracted. If the saw back sensor is not active, homing cannot proceed.
CHECK
STEP // 01
Home Trolley Servo
Operator commands HOME from the computer. Trolley servo drives to home position. Controller confirms axis is referenced and ready.
PROCESS
JOB SETUP
STEP // 02
Open Job File
Operator opens job file on the computer. File contains the full member list with cut lengths for the frame to be produced.
OPERATOR
STEP // 03
Select Member from List
Operator selects the member to be cut from the job list. Program reads the required cut length for that member.
OPERATOR
STEP // 04
Load Timber Against Trolley
Operator places timber on the table and pushes it up against the trolley face. Ensure timber is seated correctly before proceeding.
ACTION
STEP // 05
Press Start Member
Operator presses START MEMBER. Program commands trolley servo to move to the exact cut length position for the selected member.
PROCESS
LID
CLOSED?
▲ YES — AIR VALVE ON NO ▶ SAW BLOCKED
CHECK // LID AIR VALVE
Lid Closed — Air Valve Active
Lid is closed. Air valve is active — saw blade is permitted to rise when THNTD buttons are pressed. Trolley movement is unaffected by lid position.
CHECK
HOLD // LID OPEN
Saw Blade Cannot Rise
Lid is open. Air valve is inactive — saw blade cannot rise even if THNTD buttons are pressed. No sensor is used. Operator must close the lid to activate the air valve before cutting can proceed.
DECISION
↩ CLOSE LID → AIR VALVE ACTIVATES → SAW CAN RISE
CUT SEQUENCE
STEP // 06
Trolley Moves to Cut Length
Trolley servo drives to exact programmed length. Trolley stops and holds position. Timber is now set at the correct cut length.
PROCESS
SAW
CONFIRM?
▲ YES — SAW RUNNING NO ▶ PROMPT OPERATOR
CHECK // SAW CONFIRM
Saw Running — Ready to Cut
Computer receives SAW CONFIRM input. Saw blade is spinning at operating speed. Proceed to two-handed tie-down.
CHECK
PROMPT // SAW NOT RUNNING
Screen Message: Start Saw
No SAW CONFIRM signal received. Computer displays on-screen prompt instructing operator to press SAW START button before cutting can proceed.
DECISION
↩ PRESS SAW START → AWAIT SAW CONFIRM
STEP // 07
Confirm Saw Back Sensor
Program confirms SAW BACK SENSOR is active — saw blade is fully retracted and clear of cutting zone. Safe to initiate cut stroke.
CHECK
STEP // 08
Hold Two-Handed Tie-Down Buttons
Operator simultaneously holds BOTH tie-down buttons and keeps them held. Both inputs must remain active throughout the full cut stroke.
ACTION
STEP // 09
Saw Advances & Cuts Timber
Air activates. Saw blade advances from cabinet below, cuts through timber at 90°. Both tie-down buttons must remain held for full cut duration.
ACTION
STEP // 10
Saw Retracts — Cut Complete
Saw blade drops back and retracts to cabinet. SAW BACK SENSOR activates confirming blade is clear. Operator releases tie-down buttons. Cut member is complete.
CHECK
NEXT MEMBER
AUTO NEXT
ENABLED?
▲ YES — AUTO ADVANCE NO ▶ MANUAL SELECT
AUTO // NEXT MEMBER
Program Advances to Next Member
Auto Next Member is enabled. Program automatically selects the next member in the job list and commands trolley to move to new cut length.
PROCESS
MANUAL // NEXT MEMBER
Operator Selects Next Member
Auto Next Member is off. Program waits. Operator manually selects next member from the job list on screen, then continues.
OPERATOR
MORE
MEMBERS?
▲ YES — LOAD NEXT TIMBER NO ▶ JOB COMPLETE
LOOP // REPEAT
Load Timber → Cut Next Member
More members remain. Operator loads next piece of timber against trolley and the cut sequence repeats from Step 04.
OPERATOR
COMPLETE // JOB DONE
All Members Cut
All members in the job list have been cut. Job is complete. Press SAW STOP to stop saw blade from spinning. Proceed to shutdown.
CHECK
↩ LOOPS BACK TO STEP 04 — LOAD TIMBER

EMERGENCY STOP — Can be triggered at any point during operation. Immediately cuts power to trolley servo motor and drops / disables all air pressure. Program halts. Machine must be reset before resuming.
